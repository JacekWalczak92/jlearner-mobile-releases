# J-Learner (Android) — wydania

Gotowe pliki APK aplikacji J-Learner są w zakładce **Releases** tego repozytorium.

Wymaga Androida 8.0 lub nowszego. Jeśli masz wersję sprzed 1.0 (AnkiFiszki / J-Learner),
najpierw ją odinstaluj — od 1.0 aplikacja jest podpisana innym kluczem.

Odcisk certyfikatu podpisu (SHA-256):

```
D9:C2:4C:0D:E1:A8:FD:72:72:06:9B:09:A3:4F:50:F1:61:6E:EF:1C:47:7C:28:BA:D5:BB:E9:AF:55:6A:42:1D
```

Wydania publikuje workflow `build-apk.yml` z repozytorium kodu (jlearner-mobile).
